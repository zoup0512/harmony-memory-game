## 🎨 架构设计

### MVVM 架构
```
Presentation Layer (UI)
    ↓
ViewModel Layer (Business Logic)
    ↓
Domain Layer (Use Cases)
    ↓
Data Layer (Repository)
    ↓
Database (Room)
```

### 技术栈
- **UI**: Jetpack Compose
- **架构**: MVVM
- **依赖注入**: Hilt
- **数据库**: Room
- **异步**: Coroutines + Flow
- **导航**: Compose Navigation
- **状态管理**: StateFlow
