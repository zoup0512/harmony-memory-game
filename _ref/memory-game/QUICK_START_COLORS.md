# 🚀 Quick Start: Colors Game

## 🎯 What is Colors?
A **Stroop effect** game where you judge if a color word matches the color it's displayed in.

---

## 🎮 How to Play

### Step 1: Read the Word
```
┌─────────────┐
│    RED      │  <- Read this word
└─────────────┘
```

### Step 2: See the Color
```
┌─────────────┐
│    RED      │  <- What color is it?
│  (in blue)  │     It's BLUE!
└─────────────┘
```

### Step 3: Compare
```
Word:  RED
Color: BLUE
Match? NO!
```

### Step 4: Click Answer
```
[  匹配  ] [不匹配]
            ↑
         Click here!
```

## ⏱️ Rules

- **Time Limit**: 30 seconds total
- **Lives**: None (wrong answer = game over)
- **Scoring**: 8 points per correct answer
- **Goal**: Answer as many as possible before time runs out

## 🎯 Tips

### 1. Focus on the COLOR, not the word
```
❌ Wrong: Read "RED" → think red
✓ Right: See blue color → compare with word
```

### 2. Don't rush on incongruent trials
```
Word: BLUE (in yellow)
Take a moment to see the actual color!
```

### 3. Trust your eyes, not your reading
```
Your brain wants to read the word automatically.
Force yourself to look at the COLOR!
```

### 4. Practice makes perfect
```
First few tries: Confusing
After practice: Automatic
```

---

## 🧠 Why is this hard?

### The Stroop Effect
```
Reading words = AUTOMATIC (fast, effortless)
Naming colors = CONTROLLED (slow, requires focus)

When they conflict:
Word "RED" in blue color
  ↓
Your brain reads "RED" automatically
  ↓
But you need to say "blue"
  ↓
Requires mental effort to override!
```

## 🎯 Quick Reference

### Controls
- **匹配 (Match)**: Word matches color
- **不匹配 (Don't Match)**: Word doesn't match color
- **⏸ (Pause)**: Pause game
- **← (Back)**: Exit game

### Feedback
- **正确！**: Correct answer (green popup)
- **Game Over**: Wrong answer or time out

### Timer
- **Green bar**: Plenty of time
- **Yellow bar**: Running low
- **Red bar**: Almost out!
