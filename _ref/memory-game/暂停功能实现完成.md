## 技术细节

### 暂停时的行为

1. **游戏流程暂停**
   ```kotlin
   fun pauseGame() {
       gameFlowJob?.cancel()  // 取消协程
       _uiState.value = _uiState.value.copy(isPaused = true)
   }
   ```

2. **UI 冻结**
   - 对话框覆盖游戏画面
   - 用户无法操作游戏
   - 游戏状态保持不变

### 恢复时的行为

1. **智能恢复**
   ```kotlin
   fun resumeGame() {
       _uiState.value = _uiState.value.copy(isPaused = false)
       
       when (_uiState.value.gameState) {
           GameFlowState.USER_INPUT -> {
               // 用户输入阶段，直接恢复
           }
           GameFlowState.GAME_OVER -> {
               // 游戏结束，不恢复
           }
           else -> {
               // 其他阶段，重新启动流程
               startGameFlow()
           }
       }
   }
   ```

2. **状态保持**
   - 分数保持
   - 生命数保持
   - 关卡保持
   - 网格状态保持

### 对话框特性

2. **颜色方案**

3. **交互**

   - 返回键关闭对话框
