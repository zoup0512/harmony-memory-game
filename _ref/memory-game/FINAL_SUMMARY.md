## 🔧 技术架构

### 核心技术
- **语言**: Kotlin
- **UI框架**: Jetpack Compose
- **架构**: MVVM
- **状态管理**: StateFlow
- **异步**: Coroutines
- **动画**: Compose Animation API

### 游戏进度系统
- **GameProgression1**: 网格大小递增（记忆类游戏）
- **GameProgression2**: 继承GameProgression1（旋转网格）
- **GameProgression3**: 元素数量递增（想象力、速度类）
- **GameProgression12**: 等式复杂度递增（Correctly）

### 共享组件
- **BaseGameScreen**: 统一的游戏界面框架

- **GameFactory**: 游戏路由系统
- **GameDataProvider**: 游戏数据管理
