## 实现的功能特性

每个游戏的暂停功能包括：

### 1. 暂停对话框
- ✅ **继续游戏** (绿色按钮) - 恢复游戏状态和计时器
- ✅ **重新开始** (蓝色按钮) - 重置游戏到初始状态
- ✅ **退出游戏** (红色按钮) - 返回游戏列表

### 2. ViewModel 实现
```kotlin
fun pauseGame() {
    timerJob?.cancel()  // 停止计时器
    _uiState.value = _uiState.value.copy(isPaused = true)
}

fun resumeGame() {
    _uiState.value = _uiState.value.copy(isPaused = false)
    if (_uiState.value.gameState == GameState.PLAYING) {
        startTimer()  // 恢复计时器
    }
}

fun restartGame() {
    _uiState.value = _uiState.value.copy(isPaused = false)
    startGame()  // 重新开始游戏
}
```

### 3. UI 集成
- 暂停按钮点击触发暂停
- 暂停对话框覆盖游戏界面
- 对话框外点击或返回键可关闭对话框
- 暂停期间游戏逻辑完全停止

## 技术实现细节

### 架构模式
- **MVVM架构**: ViewModel管理游戏状态，UI响应状态变化
- **Kotlin Coroutines**: 使用协程管理计时器和异步操作
- **Jetpack Compose**: 现代化的声明式UI框架
- **StateFlow**: 响应式状态管理

### 暂停机制
1. **计时器暂停**: 取消协程Job，停止时间流逝
2. **状态保存**: 保存当前游戏状态（关卡、分数、生命值等）
3. **恢复逻辑**: 根据游戏状态智能恢复计时器和游戏流程
4. **重启功能**: 完全重置游戏到初始状态
