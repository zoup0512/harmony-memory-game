## 💡 提示

### 如何添加新游戏

在 `GameDataProvider.kt` 中添加：

```kotlin
Game(
    id = 24,
    name = "新游戏名称",
    description = "游戏描述",
    category = GameCategory.MEMORY,
    iconResId = 0,
    isLocked = false,
    requiredStars = 0
)
```

### 如何修改游戏解锁条件

修改 `requiredStars` 和 `isLocked` 属性：

```kotlin
Game(
    id = 1,
    name = "记忆网格",
    // ...
    isLocked = true,      // 改为 true 锁定
    requiredStars = 50    // 修改所需星星数
)
```
