## 为什么这两个游戏特别复杂？

### 1. Jetpack Compose 的限制
- **Canvas API 不同**: 旧项目使用 Android View 的 Canvas，新项目使用 Compose Canvas
- **手势处理不同**: Compose 的手势 API 与 View 系统完全不同
- **动画系统不同**: 需要重新设计动画逻辑

### 2. 游戏逻辑复杂
- **248**: 需要实现类似消消乐的游戏逻辑
- **Laser**: 需要实现激光反射的物理计算

### 3. 性能要求高
- **实时绘制**: 需要 60fps 的流畅度
- **复杂计算**: 路径计算、碰撞检测等

### 248 简化版实现思路

```kotlin
// 使用 Compose Grid 而不是 Canvas
@Composable
fun Game248Screen() {
    LazyVerticalGrid(columns = GridCells.Fixed(6)) {
        items(cells) { cell ->
            CellItem(
                cell = cell,
                onClick = { onCellClick(cell) }
            )
        }
    }
}

// 简化的连接逻辑
fun onCellClick(cell: Cell) {
    if (selectedCells.isEmpty() || 
        cell.color == selectedCells.last().color) {
        selectedCells.add(cell)
    } else {
        clearSelection()
    }
}
```
