## 本次完成的游戏 (2个灵活性类游戏)

### 1. Paper Planes (Game 14) - 纸飞机 🆕
**文件**:
- `PaperPlanesViewModel.kt`
- `PaperPlanesGameScreen.kt`

**特性**:
- 两种游戏模式：移动方向模式和朝向模式
- 6架纸飞机在屏幕上移动
- 4朵云彩作为背景
- 30秒计时器
- 3条生命系统
- 滑动手势识别

**游戏流程**:
1. 纸飞机在屏幕上移动
2. **移动方向模式**（青色飞机）：根据飞机移动的方向滑动
3. **朝向模式**（橙色飞机）：根据飞机朝向的方向滑动
4. 正确滑动进入下一关

**难度递增**:
- Level 1-10: 所有飞机相同速度
- Level 11+: 飞机不同速度（增加难度）
- Level 16+: 云朵开始移动（左或右）

**UI设计**:
- Canvas绘制纸飞机和云朵
- 纸飞机形状：三角形
- 云朵形状：多个圆形组合
- 飞机根据朝向旋转（0°/90°/180°/270°）
- 流畅的动画效果

### 2. Like Previous (Game 15) - 像之前的吗 🆕
**文件**:
- `LikePreviousViewModel.kt`
- `LikePreviousGameScreen.kt`

**特性**:
- 判断当前元素是否与之前元素相同
- 7种形状：圆形、方形、三角形、菱形、星形、六边形、心形
- 10种颜色
- 30秒计时器
- 3条生命系统

**游戏流程**:
1. 显示当前元素（形状+颜色）
2. 如果有之前的元素，显示在上方
3. 玩家判断当前元素是否与之前相同
4. 点击"相同"或"不同"按钮
5. 正确进入下一关，当前元素成为下一轮的"之前元素"

**难度递增**:
- Level 1: 自动跳过（建立基准）
- Level 2-5: 4种颜色，7种形状
- Level 6-10: 4种颜色，5种形状
- Level 11-15: 4种颜色，4种形状
- Level 16+: 1种颜色，3种形状（最难）

**UI设计**:
- 上方显示之前的元素（小卡片）
- 中间显示当前元素（大卡片）
- 底部两个按钮："相同"和"不同"
- 卡片带阴影和圆角
- 清晰的视觉层次
