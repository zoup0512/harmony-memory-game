## 🏗️ 技术架构

### 核心组件

#### 1. GameFactory（游戏工厂）
- **文件**: `GameFactory.kt`
- **功能**: 根据gameId路由到对应游戏
- **优势**: 集中管理，易于扩展

#### 2. BaseGameViewModel（基础ViewModel）
- **文件**: `common/BaseGameViewModel.kt`
- **功能**: 提供通用游戏逻辑
- **包含**: 倒计时、星星计算、协程管理

#### 3. SimpleGameTemplate（游戏模板）
- **文件**: `common/SimpleGameTemplate.kt`
- **功能**: 通用游戏界面模板
- **包含**: 顶部栏、统计卡片、游戏内容区

#### 4. PlaceholderGameScreen（占位符）
- **文件**: `common/PlaceholderGameScreen.kt`
- **功能**: 快速原型和占位符
- **优势**: 快速实现基础框架

### 设计模式

1. **MVVM架构**: ViewModel + StateFlow + Compose
2. **工厂模式**: GameFactory统一管理游戏创建
3. **模板方法**: 通用组件和基类
4. **依赖注入**: Hilt管理依赖
