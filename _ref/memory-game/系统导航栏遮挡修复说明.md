# 系统导航栏遮挡问题修复

## 问题描述

生命数（♥）栏被系统导航栏挡住了。

## 问题分析

### 原因

1. **Edge-to-Edge 模式已启用**
   - `MainActivity` 中设置了 `WindowCompat.setDecorFitsSystemWindows(window, false)`
   - 这使得应用内容可以延伸到系统栏（状态栏和导航栏）下方

2. **缺少 WindowInsets 处理**
   - `BaseGameScreen` 的 `Scaffold` 没有处理系统栏的 insets
   - 导致内容被系统导航栏遮挡

### Edge-to-Edge 模式说明

Edge-to-Edge 是 Android 的现代 UI 设计模式：
- 应用内容延伸到屏幕边缘
- 可以在系统栏下方绘制内容
- 需要手动处理 insets 以避免内容被遮挡

---

## 解决方案

### 修改的文件

**BaseGameScreen.kt**
- 在 `Scaffold` 上添加 `windowInsetsPadding(WindowInsets.systemBars)`
- 这会自动为系统栏（状态栏和导航栏）添加内边距

---

## 详细修改

### BaseGameScreen.kt

#### 修改前

```kotlin
Scaffold(
    topBar = {
        // 顶部栏
    }
) { paddingValues ->
    // 内容
}
```

#### 修改后

```kotlin
Scaffold(
    modifier = Modifier
        .fillMaxSize()
        .windowInsetsPadding(WindowInsets.systemBars),  // 🆕 处理系统栏 insets
    topBar = {
        // 顶部栏
    }
) { paddingValues ->
    // 内容
}
```

## 技术说明

### WindowInsets

`WindowInsets` 表示系统 UI 元素占用的屏幕区域：

- **状态栏 (Status Bar)**: 屏幕顶部，显示时间、电池等
- **导航栏 (Navigation Bar)**: 屏幕底部，显示返回、主页、多任务按钮
- **系统栏 (System Bars)**: 状态栏 + 导航栏

### windowInsetsPadding

`windowInsetsPadding(WindowInsets.systemBars)` 的作用：

1. **自动计算内边距**
   - 检测系统栏的高度
   - 为内容添加相应的内边距

2. **适配不同设备**
   - 自动适配不同屏幕尺寸
   - 支持手势导航和按钮导航
   - 支持横屏和竖屏

3. **响应系统变化**
   - 键盘弹出时自动调整
   - 系统栏显示/隐藏时自动调整

## 其他可能的解决方案

### 方案 1: 使用 systemBarsPadding（当前方案）

```kotlin
Scaffold(
    modifier = Modifier
        .fillMaxSize()
        .windowInsetsPadding(WindowInsets.systemBars)
) { ... }
```

**优点**:
- 简单直接
- 自动处理所有系统栏
- 适配所有设备

**缺点**:
- 内容不会延伸到系统栏下方

### 方案 2: 只处理导航栏

```kotlin
Scaffold(
    modifier = Modifier
        .fillMaxSize()
        .windowInsetsPadding(WindowInsets.navigationBars)
) { ... }
```

**优点**:
- 只处理导航栏
- 状态栏下方可以绘制内容

**缺点**:
- 需要单独处理状态栏

### 方案 3: 手动添加底部内边距

```kotlin
Column(
    modifier = Modifier
        .fillMaxSize()
        .padding(bottom = WindowInsets.navigationBars.asPaddingValues().calculateBottomPadding())
) { ... }
```

**优点**:
- 精确控制内边距位置

**缺点**:
- 代码复杂
- 需要手动处理各种情况

## 相关知识

### Edge-to-Edge 设计

Edge-to-Edge 是 Android 推荐的现代 UI 设计：

1. **Material Design 3**
   - 内容延伸到屏幕边缘
   - 沉浸式体验
   - 更大的可用空间

2. **实现步骤**
   ```kotlin
   // 1. 启用 edge-to-edge
   WindowCompat.setDecorFitsSystemWindows(window, false)
   
   // 2. 处理 insets
   Modifier.windowInsetsPadding(WindowInsets.systemBars)
   ```

3. **注意事项**
   - 必须处理 insets
   - 考虑不同设备
   - 测试各种场景

### WindowInsets API

```kotlin
// 所有系统栏
WindowInsets.systemBars

// 只有状态栏
WindowInsets.statusBars

// 只有导航栏
WindowInsets.navigationBars

// IME（输入法）
WindowInsets.ime

// 显示切口（刘海屏）
WindowInsets.displayCutout
```
