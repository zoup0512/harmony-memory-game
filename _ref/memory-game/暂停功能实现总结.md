## 实现模式 (复制粘贴模板)

### ViewModel 模板

```kotlin
// 1. 在 UiState 数据类中添加
data class YourGameUiState(
    // ... 其他字段
    val isPaused: Boolean = false
)

// 2. 在 ViewModel 类中添加这三个方法
fun pauseGame() {
    timerJob?.cancel()  // 如果有计时器
    _uiState.value = _uiState.value.copy(isPaused = true)
}

fun resumeGame() {
    _uiState.value = _uiState.value.copy(isPaused = false)
    // 根据游戏类型恢复逻辑
    if (_uiState.value.gameState == GameState.PLAYING) {
        startTimer()  // 或 startLevelTimer() 等
    }
}

fun restartGame() {
    _uiState.value = _uiState.value.copy(isPaused = false)
    startGame()
}
```

### GameScreen 模板

```kotlin
// 1. 在 import 部分添加
import com.memory.brain.training.games.presentation.screens.game.common.PauseDialog

// 2. 在 Composable 函数中，BaseGameScreen 之前添加
if (uiState.isPaused) {
    PauseDialog(
        gameName = game?.name ?: "",
        onDismiss = { viewModel.resumeGame() },
        onResume = { viewModel.resumeGame() },
        onRestart = { viewModel.restartGame() },
        onExit = onNavigateBack
    )
}

// 3. 修改 BaseGameScreen 的 onPauseClick
BaseGameScreen(
    // ... 其他参数
    onPauseClick = { viewModel.pauseGame() }  // 修改这一行
) {
    // ...
}
```

## 注意事项

1. **计时器恢复逻辑**
   - 有些游戏使用 `startTimer()`
   - 有些游戏使用 `startLevelTimer()`
   - 有些游戏使用 `startGameFlow()`
   - 需要根据具体游戏调整 `resumeGame()` 中的恢复逻辑

2. **游戏状态检查**
   - 大多数游戏使用 `GameState.PLAYING`
   - 有些游戏使用 `GameFlowState.USER_INPUT`
   - 需要根据具体游戏调整状态检查

3. **单文件游戏**
   - 对于单文件游戏（如 CatchThem, Game248, Laser），所有修改都在一个文件中完成
