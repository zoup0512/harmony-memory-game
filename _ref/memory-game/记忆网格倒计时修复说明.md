# 记忆网格游戏 - 倒计时功能修复

## 问题描述

用户反馈："记忆网格"游戏最初的版本有 ♥（代表剩余的命数）以及 ⏰（倒计时），但现在的版本没有了。

## 问题分析

### 1. 生命数（♥）状态

**结论**: ✅ **生命数功能正常**

- `BaseGameScreen` 已经实现了生命数显示功能
- `MemoryGridGameScreen` 正确传递了 `lives = uiState.lives`
- 生命数应该是正常显示的（3个红心图标）

### 2. 倒计时（⏰）状态

**结论**: ❌ **倒计时功能缺失**

- 旧项目使用 `TimerView` 组件显示倒计时
- 新项目的 `BaseGameScreen` 有 `timerOverlay` 参数支持
- 但 `MemoryGridGameScreen` 没有使用这个功能

## 解决方案

### 修改的文件

1. **MemoryGridViewModel.kt**
   - 在 `MemoryGridUiState` 中添加倒计时状态
   - 在 `startGameFlow()` 中实现倒计时逻辑

2. **MemoryGridGameScreen.kt**
   - 使用 `timerOverlay` 参数显示倒计时
   - 导入 `TimerOverlay` 组件

## 详细修改

### 1. MemoryGridViewModel.kt

#### 添加倒计时状态

```kotlin
data class MemoryGridUiState(
    val level: Int = 1,
    val score: Int = 0,
    val lives: Int = 3,
    val gameState: GameFlowState = GameFlowState.READY,
    val gridSize: Int = 3,
    val winCells: Int = 3,
    val pattern: List<Int> = emptyList(),
    val userSelections: List<Int> = emptyList(),
    val readyTimerSeconds: Int = 0,      // 🆕 倒计时秒数
    val showReadyTimer: Boolean = false  // 🆕 是否显示倒计时
)
```

#### 实现倒计时逻辑

```kotlin
private fun startGameFlow() {
    gameFlowJob?.cancel()
    gameFlowJob = viewModelScope.launch {
        // State 1: Ready (800ms) - 显示倒计时
        _uiState.value = _uiState.value.copy(
            gameState = GameFlowState.READY,
            showReadyTimer = true,
            readyTimerSeconds = 3
        )
        
        // 倒计时动画：3, 2, 1
        repeat(3) { index ->
            delay(267)  // 800ms / 3 ≈ 267ms per count
            _uiState.value = _uiState.value.copy(
                readyTimerSeconds = 3 - index - 1
            )
        }
        
        _uiState.value = _uiState.value.copy(showReadyTimer = false)
        
        // State 2: Grid Animation (1000ms)
        _uiState.value = _uiState.value.copy(gameState = GameFlowState.GRID_ANIMATION)
        delay(1000)
        
        // ... 其余代码
    }
}
```

            )
        }
    }

}

## 功能说明

### 倒计时显示

1. **显示时机**: 在 Ready 阶段（游戏开始前）
2. **倒计时内容**: 3 → 2 → 1 → ✓
3. **显示时长**: 约 800ms（每个数字约 267ms）
4. **显示样式**: 
   - 白色圆形背景
   - 大号数字（48sp）
   - 绿色文字
   - "准备好！"提示文字
   - 最后显示对勾图标

### 生命数显示

1. **显示位置**: 顶部栏右侧
2. **显示内容**: 红色心形图标 ♥
3. **数量**: 初始3个，每次失败减少1个
4. **颜色**: 红色 (#F44336)

---

## 游戏流程

```
1. Ready (800ms)
   ├─ 显示倒计时: 3 → 2 → 1 → ✓
   └─ 显示生命数: ♥♥♥

2. Grid Animation (1000ms)
   └─ 网格单元格动画

3. Show Challenge (1200ms + level*200ms)
   └─ 显示需要记忆的位置（绿色）

4. User Input
   ├─ 用户点击记住的位置
   ├─ 正确：继续下一关
   └─ 错误：失去一条生命
```
